# dice_game

A fun and interactive multi-player dice rolling game written in Python. Each player takes turns rolling the dice to reach a maximum score of 50. Roll wisely — if you hit a 1, your turn ends with no points!

## ✨ Features
- 2 to 4 player support
- Turn-based gameplay with score tracking
- Risk-based rolling (roll a 1 and lose your turn’s points)
- Easy to run from the command line
